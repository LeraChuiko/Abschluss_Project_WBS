# Personal Finance Tracker (Abschluss Project)

One GitHub repository, two folders:

- `finance-tracker-backend` — Express + TypeScript + MongoDB (this week)
- `finance-tracker-frontend` — React (later)

## How to run the backend (later)

```bash
cd finance-tracker-backend
npm install
cp .env.example .env
npm run dev
```

Then open `http://localhost:3000/api/health`.

## Docs

- `PROJECT_CONTEXT.md` — product description (user stories)
- `DECISIONS.md` — locked rules so the API does not change randomly
- `API_CONTRACT.md` — list of URLs the frontend will call
